Объектно-ориентированная архитектура Matplotlib (памятка к защите РГР)

Иерархия объектов строится по схеме: Figure -> Axes -> Artist.
1. Figure (холст / окно) — верхнеуровневый контейнер, который хранит все подграфики (Axes), общий заголовок (suptitle) и отвечает за экспорт изображения в файл (fig.savefig).
2. Axes (система координат / область построения) — центральный объект для отрисовки данных; именно через его методы (ax.hist, ax.plot, ax.boxplot, ax.axvline, ax.set_title) создаются визуальные элементы.
3. Artist (графический примитив) — базовый класс для всех видимых объектов на холсте, которые отрисовываются рендерером.

Основные классы-наследники Artist внутри Axes:
- Axis (оси XAxis и YAxis) — управляют числовыми шкалами, делениями (Ticks) и подписями значений на осях.
- Line2D — представляет кривые графиков и опорные линии (например, кривая нормальной аппроксимации и вертикальные линии лимитов MAX_DAYS / MAX_BUDGET).
- Patch — двумерные геометрические фигуры с заливкой: прямоугольные столбцы гистограмм (Rectangle) и «ящики» на диаграммах размаха (boxplot).
- Text — все текстовые объекты графика: заголовки, подписи осей (xlabel/ylabel) и элементы легенды.

Почему используется объектный API (fig, ax = plt.subplots(...)) вместо pyplot: явная привязка методов к конкретному экземпляру Axes исключает путаницу при построении многопанельных фигур и делает код предсказуемым.
